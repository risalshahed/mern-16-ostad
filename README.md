## Download & Run the Project

### Clone the Repository
```bash
git clone https://github.com/risalshahed/mern-16-ostad.git
```

### Switch to the Branch
```bash
git switch module-21-payment-server
```

### Install Dependencies
```bash
npm i
```

### Run the Server
```bash
npm run dev
```

### Add a Payment Gateway Method

```bash
POST http://localhost:5000/pay
```
